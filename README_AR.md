# موقع جدول التدريبات

هذا الموقع عبارة عن نسخة قابلة للنشر من ملف جدول التدريبات. الموقع يستخدم Supabase الموجود داخل الملف لتخزين التدريبات والحسابات، لذلك بيانات التدريبات لا تعتمد على جهاز الزائر.

## النشر على Vercel
1. ادخل إلى Vercel.
2. أنشئ مشروعًا جديدًا وارفع هذا المجلد أو ملف `index.html`.
3. لا تحتاج إلى build command؛ الموقع static.
4. بعد النشر ستحصل على رابط يمكنك إرساله لأي شخص.

## مهم قبل الاستخدام الفعلي
الملف الحالي يستخدم جدول `accounts` ويخزن كلمة المرور داخل الجدول، ثم يجري تسجيل الدخول من المتصفح. هذا مناسب للتجربة فقط وليس نظام حسابات آمنًا لموقع عام.

كذلك يجب التأكد من إعداد Row Level Security في Supabase قبل مشاركة الموقع مع أشخاص غير موثوقين.

## البيانات
التدريبات تُقرأ من جدول `trainings` وتُحفظ فيه، والملف يعرض رسالة تفيد بأنها مشتركة بين كل من يفتح الموقع. لذلك نشر الصفحة على Vercel لا يمسح البيانات الموجودة في Supabase.
